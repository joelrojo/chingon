# chingón — how to work here

> **Movement disturbs. Stillness reveals.**
> Beneath that: **technology remembering that it is nature too.**

Every session: read `direction.md` in full before touching anything. It is one file on purpose.

## Rules

- `direction.md` is canon — only Joel-approved direction lives there. Don't change its meaning without his say; tightening language is fine.
- Everything else — proposals, explorations, open items — goes in `seeds.md`, dated. Promote to canon only when Joel confirms.
- New raw input (briefs, notes, dumps) gets folded into `seeds.md` or canon directly. No inbox, no duplicate homes.
- Keep the repo almost radically simple. Resist adding folders, tooling, or docs before the thing they document exists.
- When the site exists it lives in `site/`, and build docs live with it.
- Personal context (voice, projects, people): `~/neo` — follow its `AGENTS.md` reading map. Project status: `~/neo/work/projects/chingon.md`.

## Git

- Commit directly to `main`, terse messages. The founding brief is commit 1 of `direction.md` — git history is the archive; don't add archive folders.
- No remote yet. Once one exists: pull before working, push after committing.
