# chingón

The home of [chingon.io](https://chingon.io) — a small living system on the internet.

> Movement disturbs. Stillness reveals.

- `direction.md` — the canon. Read it before doing anything.
- `seeds.md` — proposals and open items, not yet canon.
- `moodboard/` — concept images. Atmosphere, not comps.
- `site/` — the build, when it begins.

The founding brief is commit 1 of `direction.md`. History lives in the rings.
